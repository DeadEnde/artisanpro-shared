# HorizonX Design Analysis for ArtisanPro
**Date:** 2026-08-27
**Website:** https://horizonx.so/explore (187 results)
**Project:** ArtisanPro SaaS for artisans

## 1. Mosk - BEST MATCH FOR ADMIN DASHBOARD
**Link:** https://horizonx.so/explore/mosk
**Overview:** Dark-mode B2B SaaS analytics, bold editorial, abstract charts, strong CTAs, integration cues Notion/Slack/Adobe/Figma
**Match:** ArtisanPro Admin has dark green sidebar + light/dark + 4 cards + revenue 0 MAD + sessions 0 + Security banner + mobile bottom nav
**Apply:** Keep green construction design, add Mosk abstract chart imagery to revenue chart empty state, high-contrast CTA for Export/Security logs, integration badges Supabase/Vercel/Google

## 2. Aether Grid App - BEST MATCH FOR CLIENT DASHBOARD
**Link:** https://horizonx.so/explore/aether-grid
**Overview:** Smart-home control, connected devices, energy signals, live telemetry, command center
**Match:** Client dashboard modules Peinture 99 MAD/Carrelage, single session tracking device/browser/OS online/offline 2min, entitlements is_unlocked
**Apply:** Module cards like device cards with on/off toggle for is_unlocked + live stats (3 devis, 86m²), sessions list with green dot online <2min like live telemetry

## 3. Energy Command Dashboard - BEST MATCH FOR CHANTIER
**Link:** https://horizonx.so/explore/energy-command-dashboard
**Overview:** Interactive smart-building 18-floor, Three.js city, energy KPIs, savings forecasts, glassmorphic controls, light/dark, 3D interaction
**Match:** Peinture Workspace room type, ceiling, doors/trims, interior/exterior, wall condition, CostBreakdownForm, PricingStrategyPanel, LibraryPanel, Projects by city
**Apply:** Room selector like floor selector (visual building selectable rooms), PricingStrategyPanel glassmorphic with savings forecast Baseline 5050 MAD Optimized 4300 MAD Savings 750 MAD, Projects map view Morocco

## Recommended Design System
- Cards: Icon + Label + Value + Change ↗ live + abstract chart background (Mosk)
- Module Cards: Header Name+Toggle is_unlocked + Stats devis/m² + Expiry formatDate + CTA upgrade/contact (Aether)
- Sessions: Dot online + Device + Browser/OS + LastSeen relativeTime + ForceLogout (Aether telemetry)
- Room Selector: Building visual selectable rooms + RoomDetails (Energy floor selector)
- PricingStrategyPanel: Glassmorphic + Strategy floor/ceiling/profit + Forecast Baseline/Optimized/Savings (Energy)
